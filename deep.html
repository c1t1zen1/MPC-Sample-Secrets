Secret Manual

The quick-start covers maybe a third of this machine, and even the full PDF hides gold in footnotes. This page collects it: every combo in one searchable codex, every parameter on every page, all 60+ effects, the hard limits and how to get around them, and how the docs changed between revisions.

3.1

What the quick-start never told you

Each of these is in the official PDF or release notes, or verified by the community, but buried. Badges show the evidence level.

Zoom exists

zoom the waveform at Start / End / Loop, in Trim and in Chop. Reviewers missed it because it isn't printed anywhere on the panel. manual

Chop while you sample

During a recording, tapping other pads drops slice markers live. Lazy-chop a record in one pass. manual

Two recall buffers

Audio input is always being buffered (), and so are your pad hits (, "MIDI retrospective record"). manual

Pad Link

Play page : trigger another pad from the same bank whenever this one fires. Layer a sub under a kick, or melody + break. Bank-local only. manual

Trigger offset

Play page K3 delays sample start after the hit (0–100%). Push snares back for a lazy pocket, or build flams. Automatable. manual

Decay From Start / End

on Amp/Filter Env. With Decay From Start a looping one-shot fades out on its own, so loops become gated swells. manual

MPC3000 filter

Filter type Classic is modelled on the MPC3000 low-pass and behaves differently with resonance up. Plus LPF/HPF/BPF in 2- and 4-pole. manual

Vintage file formats

The importer reads .snd (MPC2000-era) and .s1s/.s3s (S1000/S3000-era) alongside WAV, AIFF, MP3, FLAC and OGG. Old Akai disk dumps live again. spec

Warp = Seq

Set Warp (K3, Tune page) to Seq and give it # Beats (): the loop follows sequence tempo. flips stretch ↔ re-pitch. manual

Per-sequence tempo

Seq mode B2 toggles SEQ (each sequence keeps its own BPM) and GBL (one tempo). Tempo changes per song section, for free. manual

Any bar length

K1 jumps in powers of two, while picks any length from 1 to 128. With time signatures, you get 3-bar phrases in 7/8. manual

RT swing vs Time Correct

Seq K3 swing is live and non-destructive. Time Correct swing is applied with Do It, and its value also swings Note Repeat. manual

Exclude pads from Knob FX

In FX Select, lit pads get the effect and dim pads don't. Put the Pumper on everything but the kick and you've got sidechain without a sidechain input. manual

Load a kit, skip the beats

Project › Load › Kits: ENCODER push loads the kit with 4 starter sequences; B3 Load Kit loads samples only. manual

Program Change → sequence

MIDI Config › Receive Program Change = Sequence: a foot switch or DAW can change song parts. manual

Fader LED tells the value

Brighter = higher. For Pan/Tune it's brightest at the center. That's how to find the pickup point blind on a dark stage. manual

LED language

Button bright = active · dim = available · off = unavailable. Hold SHIFT: dim red = has a 2nd function, bright red = that function is active. manual

USB MIDI needs a switch

The USB MIDI port appears but stays silent until MIDI Config › MIDI Port = USB. Pads 1–16 answer notes 36–51. verified

Export Song → Sequence

Since 1.2 a whole arrangement can become one long sequence, so you can record FX moves and automation across the full song. 1.2

Attack default changed

Since 1.3, fresh recordings get Amp Attack 2 instead of 0 (kills clicks). If your old chops click, that's why. 1.3

Live FX on a synth

Input Config › Monitor On plus Rec Input Effects prints Knob FX while sampling: Amp Sim on a drum machine, Tape Delay on vocals. manual

3.4

Pad FX: 16 pressure effects

PAD FX, then pads 1–16. Harder press = more effect (poly aftertouch). Four can run at once; a fifth bypasses the oldest until you let it go. B1 latches the current amount. They hit the whole mix.

Source: User Guide v1.3.0, Pad FX table . Filter pads 6–8 have their own tempo-synced LFO (Speed + Range).

3.5

Knob FX: the 28-effect rack

One at a time, on the pads you choose. to pick, KNOB FX to drive with K1–K3; hold SHIFT for the second row of parameters.

Source: User Guide v1.3.0, Knob FX table . MPC 3.8 ported several of these (Color compressor, tape & vinyl emulators, vintage emulation) to the big MPCs .

3.6

Flex Beat & the Color compressor

Flex Beat

. Sixteen slots of time-based mangling (beat chops, DJ-style scratches, trance gates) applied to the whole sequence while it plays. PAD 1 is the empty, dry slot. Slot names appear on screen; the manual doesn't list them.

K1One Shot (returns to PAD 1 when done) ↔ Loop (repeats until changed)
K3Dry/Wet 0–100%
B3Quantize: start on the next division

known issue glitches while tempo changes, so go 100% dry first.

Color compressor

. A "pumping" compressor that also does gentle peak control. Makeup gain is automatic.

B1COLOR: parallel bass boost + slight pitch wobble + saturation ("tape warmth")
B3Bypass / engage
K1Attack 0.1–150 ms
K2Release 3–300 ms
K3Amount 0–100% (threshold + ratio in one)
SHIFT+K3In Boost: hit it harder
3.7

Limits & workarounds

It's a small box. Here is where you'll hit walls, and the moves the community uses to climb them.

WallWorkaroundSrc
Only one Knob FX at a timePrint it: resample with the FX on, then load the next FX. Or print while sampling with Rec Input Effects.
32 stereo voicesResample busy loops into one pad; set hats to Mono; use Mute Groups so tails cut.
128 samples, one per pad; can't add a second kitStart from Load Kit (B3), extract only the slices you need, or pre-build projects on a computer (MPCTK, Kit Maker).
No keygroups / chromatic instrument16 Levels → Tune (PAD 4 = root), or generate scale-mapped pad banks with MPCTK.
No "chop to new kit" extracts slices one at a time to the next free pads.
No stems, no per-track FX routingSolo with MUTE and record each part over USB audio into a DAW, or open the project in MPC 3.8+ and mix there.
No piano rollStep Edit: encoder per step, fader nudges timing, K3 velocity.
Time-stretch can sound roughUse Warp mode Pitch for classic re-pitch character, then resample.
One MIDI out channelSequence one external device, or chain gear with MIDI Thru.
Slice edits can't be undoneSave the project (or a sample copy) before surgery.
Song→Sequence over 128 barsLength becomes uneditable: export shorter sections.
Tiny speaker, no bassHeadphones for mixing; the speaker is a sketchpad.
3.8

Recipes & sound-design tricks

R145-RPM pitch trick

Old-school sampler move: sample the record at 45 RPM (shorter, brighter, more fits in a short buffer), then drop it back down. Tune page K1 semi (−5 ≈ 45→33), or Warp mode Pitch. Finish with Knob FX Vintage Emulator SP1200 and filter type Classic.

R2MPC60 swing pocket

Record unquantized, then → B2 all → K1 1/16 → K3 swing in the high 50s to low 60s % → B3. Ride Seq K3 for live push. Glue with Vintage Emulator MPC60.

R3Bounce & stack

Busy drums + one FX: resample () to a pad, clear the source pads, load the next Knob FX, record the next layer. Repeat. It gets around both the 32-voice and one-Knob-FX limits.

R4Always-on jam recorder

Input Config: Source Rear, Monitor On. Noodle on your synth all night. When magic happens: . It's on a pad, ready to chop.

R5Granular room tone

Sample 20 s of room on Mic → LOOP + (Note On) → long release. Under it, lean on Pad FX 12 Granulator: pressure is your density fader.

R6Dub-siren throws

Knob FX Spring Reverb on the snare only. During playback hit Pad FX 15 Delay (K3 Ping-Pong), B1 latch on the last beat, then unlatch at the drop.

R7Percussion loop lock

Shaker loop on a pad → LOOP → Trim Loop Lock on. Now moving Start drags the loop with it: scrub the groove without re-aligning.

R8Arrangement-wide FX pass

Build Song () → B1 → B3 export as sequence → select it → SEQ RECORD and ride filter / Knob FX across the whole track as one take.

R9Layered kick via Pad Link

Kick on pad 1, sub/808 on pad 2. On pad 1's Play page set Pad Link → 2. Mix each layer separately with its own envelope and filter.

R1016 Levels filter ride

Select a stab → 16 LEVELS → → Filter. Pads 1–8 sweep closed-to-current cutoff, 9–16 current-to-open. Finger-drum a filter riser.

Recipes combine documented functions . Swing percentages and the 45-RPM trick are classic sampler craft and a matter of taste.

3.9

Manual revision diff & conflicts

We text-diffed every public PDF revision. Here's what changed, and where official sources disagree.

RevisionChangeLink
v1.0Launch text. Spec table: "MPC Sample projects can be loaded in MPC3".PDF
v1.0 RevBMPC3 line walked back: "Project import and export is not currently supported… upcoming firmware… MPC 3.8 and higher".PDF
v1.0 RevCMIDI jacks now specified as TRS Type A. Windows 10 users told to use the desktop updater, not the web page.PDF
v1.3.0 RevAAdds Normalize (SHIFT + B2 in Trim) and the Takeover settings (Pickup / Scaled / Instant).PDF

conflict Recall length

Manual body: last 25 s of input. Spec table: "30 seconds of audio or pad performance". Andy Mac also says 25 s.

conflict Battery

Manual: ~5 h continuous playback. FAQ: up to 6 h.

conflict MIDI adapter in the box?

Manual: TRS→DIN adapters "not included". FAQ: "The included TRS to DIN adapter is Type-A".

conflict FX into the sequence

MusicTech's review says effects can't be recorded into a sequence. Akai's FAQ says Knob FX and Pad FX adjustments can be recorded as automation. Test on current firmware.
